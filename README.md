1. 原仓库 `tarot-cards` 只读，不修改、不删除、不覆盖。
2. 所有整理、拆分、重构只在 `tarot2` 中进行。

4. 原 `index.html` 体积较大，后续建议拆分为：

   - `src/styles.css`：样式
   - `src/app.js`：交互逻辑
   - `src/tarot-data.js`：塔罗牌数据
